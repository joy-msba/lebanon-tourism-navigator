# Lebanon Tourism Opportunity Navigator

An interactive Streamlit application for exploring potential tourism
opportunities and tourism service conditions across Lebanese towns
using 2023 tourism data.

## Features

The app includes a strategic tourism opportunity matrix, linked
geographic and tourism service interactions, an interactive treemap,
dynamic insights, and a town shortlist.

Explore the Lebanon Tourism Opportunity Navigator here https://lebanon-tourism-navigator.streamlit.app/
